# Game Hot 公共阅读站

公开游戏竞品情报：榜单、游戏数据、原文链接、日期筛选、期间汇总、对比与导出。

v2行动者雷达：50个厂商、平台、发行、买量变现、奖励游戏、归因数据与引擎工具行动者，59个自动来源。新闻发现约每小时，官方RSS每3小时；可按分类、行动者、日期筛选、关注、展开事件报道、读取与导出09:00版每日简报。关注与笔记均仅保存在浏览器。

参考 [AIHOT 官方框架](https://github.com/KKKKhazix/AIHOT)，具体迁移与差异见 [迁移说明](docs/aihot-migration.md)。当前为透明规则筛选与保守标题归组，未开启模型双评分、翻译或AI事实核查。官方发布、媒体发现、效果主张与实测结论分别标识；热度不证明事实成立。

GitHub Actions约每小时采集并发布成功快照；GitHub调度可能排队。维护者可在Actions中手动运行Update Game Hot。网页的“同步最新快照”读取后台数据，不冒充触发即时采集。

体验笔记仅存于当前浏览器，不上传仓库、不与同事共享。本版不是原站云端笔记服务。

Google Play安装数据为全球累计门槛，不是精确/地区/日月下载；iOS真实下载与收入未披露的保持未知。国内榜是第三方公开Top10。失败保留上次成功快照与原采集日期。
