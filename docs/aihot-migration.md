# AIHOT → Game Hot 行动者管道

参考官方仓库 https://github.com/KKKKhazix/AIHOT ，核对版本 `6e67a9d9e8d87b95b8118a8a0b328a9bebd2bb48`。参考文件：`docs/customize.md`、`docs/sources.md`、`docs/selection.md`、`industry/prompts/selection-score.md`、`packages/backend/src/events/hot.ts`。上游 MIT 许可保留于 `third-party/AIHOT-LICENSE.txt`；未复制其品牌、字体、运营数据或非公开信源。

本次是适配现有 GitHub Pages 的轻量实现，不是部署上游 PostgreSQL / pg-boss 后端。

| 上游机制 | Game Hot 已实现 |
|---|---|
| 信源与行业实体配置 | `data/actors.json`：50 个组织，游戏品类、职能、别名、官方入口、核验记录；当前自动追踪 59 个来源 |
| 周期采集、失败可见 | 新闻发现每小时，官方 RSS 每3小时；来源身份、失败原因、最近成功时间分别记录；失败不抹历史 |
| 机械预筛、噪声抑制 | 关键词、实体匹配、广告营销抑制和透明规则优先分；分数不是准确性或盈利预测 |
| 模型独立双评分、中文写作 | **未启用**。当前无模型 API 凭据；保留原标题与短摘录，不假称完成 AI 评分/语义核查/翻译。上游 AI 门槛未套到游戏业，应先用100–200条真实标注校准 |
| 事件合并 | URL去重、保守标题相似候选、数字/主体一致性约束；跨语言不会猜测归并；可展开各条报道核查 |
| 热点 | 48h窗口、24h半衰期；同一发布域名每窗口计一次，官方RSS与Google News副本共享发布域名；多来源需至少2个候选渠道，渠道数不是独立报道证明 |
| 旧文不刷屏 | 原文日期与收录日期分开；未知/未来日期不进热点或日报；超过48h材料作为历史，不能用采集时间增加热度 |
| 日报 | 09:00边界，前24h材料，最多12件正文、10条快讯、每来源正文最多2件，7日事件去重；已出刊不自动重写 |
| 读者界面 | 行动者分类/关注/消息、事件列表、来源展开、日期筛选、每日简报、Markdown/CSV导出；浏览器关注不上传 |

## 运行

`node --test tests/*.test.mjs` → `node scripts/collect.mjs` → `node scripts/build.mjs`。预览：`node scripts/preview.mjs`（http://127.0.0.1:4318）。已有 `.github/workflows/update.yml` 负责约每小时采集、保存快照、发布 Pages；GitHub 排队可能延迟，不承诺整点完成。网站按钮读取最近云端快照，公开访客无法触发有凭据的工作流。

每日9点 Codex 推送已更新为使用行动者与事件资料，并逐条核查原文、写中文简报。网站09:00版简报由之后首次小时工作流生成，因此实际可读时间可能晚于9点。官网只核验主页/导航的行动者仍可通过媒体发现跟踪，不能把媒体发现说成官方账号直连。

行动者是重点初始名单，不代表完整覆盖整个行业；RSS可用性会随时间和网络改变。排行榜、全球累计安装门槛、资料库及体验记录继续保留。
